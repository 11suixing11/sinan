# 服务器信息展示页

登录后的默认首页为 `/#/overview`，点击服务器卡片进入 `/#/overview/<服务器 ID>`。后台侧栏的“展示首页”可返回总览，展示页右上角“进入后台”可回到既有管理界面。

本轮按用户要求复刻 NodeFlare 的**服务器信息展示界面**：全宽布局、顶部汇总、紧凑卡片、深浅主题，以及硬件/系统信息和资源曲线。后台管理、接入/升级、代理业务、诊断管理和原有登录流程保持现状。展示接口继续要求管理员登录，不新增匿名访问。

## 展示内容

- 总览：在线数量、网卡累计计数、实时上下行、名称/系统/架构/主机名搜索、在线/离线/待接入筛选。
- 卡片：处理器、内存、磁盘、交换内存、网卡速率和累计计数、运行时间、TCP 连接数与采样状态。
- 详情：硬件、系统、设备版本、心跳/采样时间，处理器/内存/磁盘/网络历史曲线，已配置的拨测结果，以及逐网卡、磁盘读写、GPU 信息。
- 深浅主题只保存在当前浏览器；样式限定在展示页，不覆盖后台。界面使用中文，不增加字体、图标 CDN 或运行时依赖。

服务器状态每 5 秒刷新；历史指标每 15 秒读取增量重叠窗口，每分钟补读所选完整窗口，补齐延迟上传的数据。页面隐藏时暂停轮询。资源曲线提供 15 分钟、1 小时、2 小时，沿用现有接口的两小时与最多 7200 条限制。拨测结果每 30 秒读取，仅展示已配置任务的记录，不创建拨测或执行诊断；24 小时视图仍受接口最多 4096 条结果限制，不承诺完整覆盖。

鼠标悬停或使用左右方向键可查看曲线读数，首尾键跳至首末采样，点击图例切换显示。缺失值、超长采样间隔保持断线，真实零值保留。曲线按时间桶保留首末值和极值，限制绘制开销。

## 数据语义

在线由面板判定，与指标新鲜度分别显示。离线、过期、无采样时间或读取失败时，不把旧速率加入实时汇总；保留最后信息并提示其状态。没有数据时显示“—”，不会补成零。接口失败不冒充空列表；登录失效仍回到原登录页。

“网卡累计”是各接口最近上报计数的合计，可能因重启重置、包含虚拟接口，不能作为计费总量或代理用户用量。总览累计仅汇总上下行计数完整的设备，缺失设备数量另行注明。成本、续费、流量配额、地区旗帜和分组等尚未对应的数据不伪造；卡片第四个资源指标使用实际交换内存。

## 来源与验证

参考本地 NodeFlare 工作树 `42eff9e07e12d6ec83e003238c1072cc5afdd39e` 的展示组件和样式，适配 Sinan 既有接口与权限。保留 [NodeFlare MIT 许可](../web/public/notices/NodeFlare.txt)，随 `web/dist` 内嵌发布，页脚可查看来源与许可。

本地验证入口：

```sh
cd web
bun run build
bun test tests
```

`web/tests/server-display.mjs` 使用提交的真实构建产物、本机静态服务及拦截 API 夹具，检查三种宽度、两种主题、数据状态、曲线交互、搜索、后台返回和权限错误；通过 `SINAN_PLAYWRIGHT_MODULE`、`SINAN_CHROME_PATH` 指定本机浏览器工具，可用 `SINAN_UI_SCREENSHOT_DIR` 保存截图。夹具测试不代表生产 Agent 或公网实机验收。CI 按当前安排保持暂停。
