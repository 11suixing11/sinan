# ADR 0038：服务器运营设置、看板访问和 GitHub Agent 下载

状态：已接受（2026-10-01 用户授权，源码实现与本地验证；CI 暂停，实机验收另行记录）。

> 后续通知范围已按用户确认由 [ADR 0039](0039-latency-tasks-and-notification-rules.md) 扩展到资源、到期、流量及 Telegram 模板和测试。

用户要求补齐隐藏节点、自动续费记录、Agent 自动更新、离线告警、下载加速、网卡流量矫正及看板是否公开，并明确 Agent 必须从 GitHub 下载，不能由面板提供二进制。

- Agent 安装与自动更新从固定仓库的 GitHub Release 获取已签名制品。面板只提供经过验证的版本、摘要和发布证明。允许管理员配置 HTTPS 镜像前缀，格式为 `https://mirror.example.com/`，请求路径为前缀加完整 GitHub URL；失败不会回退到面板。下载不发送设备身份或接入令牌，保留独立信任根、签名、平台、版本、长度和摘要校验。此项覆盖 ADR 0010、0017、0022 中 Agent 二进制必须从面板下载的约束，运行时和配置仍由面板提供。离线安装允许管理员预先下载并独立验证的发布目录。
- 看板默认需要登录。公开开关只开放专用只读接口，管理接口保持鉴权；隐藏节点在列表、详情、指标历史和拨测历史中统一排除。公开数据采用字段白名单，不公开设备凭据、公网地址、主机名、成本或告警和镜像设置。
- 自动续费仅按费用周期顺延到期记录，不向供应商付款。自动更新仍由每台服务器独立控制。
- 站内离线事件持久化，首次上报过的节点持续离线达到阈值才触发；上线后恢复。支持全局开关、单节点关闭、启动宽限和 Telegram 通知重试。机器人令牌仅在管理员写入时传入，读取仅返回是否配置，不写日志。
- 流量矫正只作用于当前账单周期及所选网卡范围，保留原始采样和日增量；调整后的上传/下载继续累加新采样。新周期自动失效，修改重置日或网卡范围后需要重新校准。它不改变代理业务账本或计量 epoch。
- 不新增依赖，沿用现有 PostgreSQL、reqwest、React 与 Bun。远端 CI、真实 Telegram 发送及多平台服务升级须单独验证，不用本地测试替代实机验收。
