# ADR 0006：特权操作经由统一 trait

- 状态：已确定，MVP 不得更改。
- 对应任务说明：第 4 节第 6 条。

## 背景

安装制品、写受保护路径、切换符号链接及管理系统服务需要特权。如果业务代码直接执行这些操作，将难以测试，也难以在以后调整权限边界。

## 决策

特权操作统一经过 `Privileged` trait；服务生命周期通过 `ServiceManager` trait 表达。MVP 中 Agent 以 root 身份运行，trait 的实现直接在进程内执行操作。禁止在 MVP 中实现独立特权 helper 进程。

调用方只依赖接口，不依赖具体命令实现。路径可配置以便使用临时目录测试；测试使用假实现记录操作和注入失败。

## 影响

当前版本没有进程级权限隔离，必须如实描述 root 运行要求。未来若替换为独立 helper，调用方接口应保持稳定；本阶段只建立实际需要的接口，不实现未来通信协议。

## 验证

审查对账和适配器调用路径，确认特权操作不绕过接口；用假服务管理器测试重载、重启、失败与回滚，避免单元测试修改主机系统状态。
