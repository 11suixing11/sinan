# ADR 0053：周期拨测使用可撤销的短期执行许可

状态：源码、工作区与实际 Web 回归完成，新版本专用 Linux 联测待完成。

主线的 `ProbeSpec.monitor` 是唯一目标授权记录。保留运营商、地区、地址家族、授权来源和适用范围，以及绑定方式、地址、端口和地址家族的原身份；不迁入预备分支的同名扁平授权模型，不改写已有目标 ID 或历史。主线迁移 `0001` 至 `0033` 原字节保留，新增拨测迁移为 `0035`，`0034` 属于独立的诊断完成确认。

新版 Agent 广告 `probe:authorized-lease`。面板在组锁和服务器行锁内，基于当前有效且启用的目标生成摘要；配置、分配、删除和自然授权到期会改变服务器修订。执行许可绑定设备和修订，最长 90 秒，并受更早的授权截止限制。同一实际登录会话短期复用已有许可不会延长截止；数据库会话摘要用于隔离重连后的签发，不出现在公开响应中。真实签发收据只记录目标摘要，按服务器保留最多 512 项、最多三小时。

Agent 冷启动不恢复旧缓存权限。许可仅在内存持有，绑定当前连接实例；GET 最长五秒，扣除请求耗时，以单调时钟执行截止。断连、换会话、GET 失败、空许可、修订或授权变化以及到期会取消在途检测。持久化只保留修订与定义高水位、采样周期和结果补传，不把持久化内容当作执行许可。采样仍使用主线四次 TCP/标准 ICMP、地址家族、四并发及存储重试机制。

新结果须携带完整执行上下文，匹配本设备真实签发收据、摘要、采样时段和当前修订/目标。没有执行证明的新结果一律 ACK 丢弃，能力降级不构成例外；旧缓存的过期或未来采样时间不阻塞同批新的有证明结果。时间窗口仍用于新有证明记录，所有记录保留字段边界、批次大小、重复 ID 和内容冲突检查；已有同 ID、同内容历史仍幂等 ACK，内容冲突仍拒绝。已撤销或删除目标的迟到结果不插入历史。匿名历史移除执行证明和授权依据，保留允许公开的监测元数据。

旧八字段协议和缺执行证明的历史结果仍可读取，旧 GET 不再签发执行权限。旧 Agent 须升级。单机、统一任务及新服务器三个管理员入口沿用原授权字段；单机编辑和删除、统一任务编辑和删除以持久化修订核对，读失败、pending、旧修订或缺失修订不得写入，失败保留草稿。

协议、Agent 回环与自有过程树、PostgreSQL 迁移和实际签发、Bun 与新构建浏览器夹具已在本轮冻结后统一验收，实际结果与原失败见[组合验收](../acceptance/open-issues-20261002.md)。包括旧缓存混合新有证明样本的真实签发回归，以及三个管理入口的修订冲突保护。专用 Debian 的新源码重启、冷启动 GET 拒绝、401/403/挂起、断连、撤销、标准 ICMP、低内存、实际 SQLite FULL、持续回环代理和心跳须另有真实收据。预备分支或旧 120 秒缓存联测的通过记录不能替代本轮实机验收；CI 暂停、生产与正式签署边界保持。
