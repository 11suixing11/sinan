# ADR 0072：有界订阅导入与不可变来源版本

> 主线整合编号 0070；作者原独立分支编号 0055。旧主线同号决策及链接保留，历史验收仅认证原冻结输入。

日期：2026-10-02。状态：已集中实现并通过本地验收；完整混合路径与专用节点验收继续后续实施。

## 范围与必要性

本步落实 [ADR 0040](0040-mixed-chains-and-subscriptions.md) 的订阅来源阶段：在代理节点页管理 HTTPS 地址或粘贴／上传内容，解析 URI、单层 Base64 URI、sing-box JSON 与 Clash/Mihomo YAML，保存任务、成功批次、明确节点身份和不可变连接版本。现有受管两跳能力继续使用原编译与发布；有序混合路径、版本应用、真实多跳及不旁路验收继续后续实现。

新增面板插件专用 `saphyr-parser = "=0.1.0"`，关闭默认功能及调试输出。JSON 继续使用已有 serde 的有界 Visitor；YAML 需要在构造对象或展开别名前逐事件限制，不能先交给通用对象反序列化器。自行编写 YAML 语法器成本和兼容风险过高；仅支持 JSON 或拒绝全部锚点不能满足已授权的四格式及有界非递归锚点需求。该固定版本为 MIT OR Apache-2.0、最低 Rust 1.85，兼容仓库最低 1.88；直接依赖为 arraydeque 与既有 thiserror。版本、功能、实际校验和与传递依赖由 Cargo.lock 锁定，源码与许可证见 [官方固定版本](https://github.com/saphyr-rs/saphyr/tree/v0.1.0/parser)。不引入第二套 URL 库，使用已有 reqwest 的 Url。

## 输入与秘密边界

完整 URL、认证头、原文、规范化连接配置及摘要只用于受保护数据库字段和内部版本关联。普通 GET、任务、错误及日志只输出验证后的公开预览与固定错误分类；不回显 URL 路径／查询、URI、认证字段、底层网络错误、内容摘要或身份指纹。没有新增应用层数据库加密保证。浏览器敏感草稿只保留当前页面内存，保存确认后立即清除；响应丢失期间以原幂等键和原请求重放。

只允许 Authorization、Cookie、X-API-Key 认证头，大小写规范化，最多三项且总计 8 KiB；拒绝空值、换行、重复项及其他头。管理员不能覆盖 Host、Origin、Referer 或 User-Agent。HTTPS 来源拒绝 userinfo、fragment、本地协议及不合法 URL。

下载最多 20 秒、三次同源 HTTPS 跳转、原文和解压后各 2 MiB。DNS 所有返回地址均必须属于允许公网范围；连接只使用同一次审查的地址，TLS 校验保持原主机。每个跳转重新检查，关闭环境代理、自动跳转与 Referer。保守拒绝 IPv4 映射、NAT64、6to4、Teredo 等可隐藏目标的特殊 IPv6 表达；特殊地址依据 [IANA IPv4](https://www.iana.org/assignments/iana-ipv4-special-registry/) 与 [IANA IPv6](https://www.iana.org/assignments/iana-ipv6-special-registry/) 表制定。gzip 先限制传输正文，再有界解压；不启用不受控自动解压。失败分为 URL、DNS、连接、TLS、超时、HTTP、重定向、编码与资源限制，不把供应方限制转为重试或 UA 伪装。

解析器最多 5000 节点、深度 64、单标量 64 KiB，并限制累计结构、字节、锚点与别名展开。拒绝重复关键字段、递归别名和 provider-only 配置，不访问嵌套来源。代理之外的路由、DNS、入站及选择组不导入；必要参数或依赖不能表达的节点保留为不支持。规范化类型依据 [固定 sing-box 1.14.2](https://github.com/SagerNet/sing-box/tree/v1.14.2/option)，SS 编码按 [SIP002](https://shadowsocks.org/doc/sip002.html) 区分 AEAD-2022。

## 身份、并发与取消

设置 revision 用于写入 CAS，身份 epoch 用于来源替换。URL、认证或输入类型更换建立新 epoch；粘贴更新明确区分同源更新与更换来源。新 epoch 清当前尝试与错误，旧任务证据和带真实 epoch 的旧成功批次保持；不能把原机场的 403 写成新机场失败。名称／周期变化不改变 epoch，同 epoch 的成功版本仍可使用。名称、顺序和认证秘密不是节点身份；本期标准格式没有独立提供方元数据 ID，仅使用整批唯一的协议／端点／SNI／传输指纹匹配。重复已校验身份标为 ambiguous，不支持项缺少可校验身份则标为 unresolved，不把未知协议解释成多个账号。两者均禁止新引用，不猜测旧绑定；凭据轮换生成新版本，缺失节点保留历史。合法的空节点集合可生成成功空批次，旧节点记为缺失；无效正文则保留上次成功，两种情形不同。

任务绑定设置 revision、epoch、解析器版本及 claim token；同源一个活动任务，跨来源最多四个。下载／解析在数据库锁外执行，入库前重新核对全部条件。取消、替换、归档及删除后迟到结果不能写入新一代。同步解析放在有界阻塞工作中，取消或期限到达后仍等待该工作退出才释放任务所有权；不把丢弃 JoinHandle 写成线程已停止。30 秒单调工作期限不因续租延长，45 秒恢复 lease 在本地工作仍存活时续租，包括等待解析退出的取消状态；进程重启后过期 lease 失效，旧 claim 不复用。单次执行入口也等全部工作退出后报告持久化错误，不通过提前丢弃工作集合“完成”其它任务。

成功批次与节点连接版本不可变；每次成功为本批节点生成新版本，内容语义摘要不包含展示名，后续跟随更新须比较语义而非版本 UUID。失败只更新最近尝试和错误，保留最近成功。304 仅沿用当前条件缓存对应的成功批次。创建及更新收据绑定精确请求，来源软删除保留历史和收据，旧请求不复活来源。归档停止刷新及新引用。当前旧两跳模型不能引用外部节点，实际依赖清单为空；后续混合路径必须加入当前、待应用及恢复版本的真实引用保护，不能把本期空清单当作该验收已完成。

未删除来源（含归档）最多 128 个，创建事务在独立短锁内核对容量；原收据重放先返回，不能被容量门禁阻止。当前节点读取最多 5000 行，优先完整展示最近成功批次，再以剩余位置展示同 epoch 的旧缺失节点；更早的缺失或歧义项从有界批次历史读取。不能让旧缺失节点占满读取额度而隐藏当前有效节点。
