# ADR 0002：Agent 三层结构与无状态适配器

- 状态：已确定，MVP 不得更改。
- 对应任务说明：第 4 节第 2 条。

## 背景

身份、传输、状态、遥测与流量账本是 Agent 的原生职责；具体运行时的命令、配置与统计接口不应渗入这些职责。

## 决策

`agent-core` 的工作区依赖只有 `adapter-sdk` 和 `protocol`，源码不允许出现 `singbox` 或 `sing-box` 字样。各 `adapter-*` 的工作区依赖只有 `adapter-sdk`。只有 `agent` 二进制入口同时依赖 core 与具体适配器，并完成注册和依赖注入。外部库遵守任务说明的依赖清单。

适配器是无状态翻译层，通过统一的 `Adapter` 接口提供 `describe`、`prepare`、`plan`、`apply`、`health`，可通过 `UsageSource` 提供累计计数。持久化和连接面板均由 core 负责；适配器不得自行承担这两项工作。每次适配器调用都必须有超时。

## 影响

core 通过模块标识和能力工作，可以注入 `FakeAdapter` 验证对账行为。适配器需要的持久状态由 core 显式传入或保存，不能隐藏在适配器内部。CI 检查 core 目录中的禁用词，依赖清单也应接受审查。

## 验证

运行 core 禁用词检查并检查工作区依赖方向；通过假适配器完成版本合并、失败回滚和意图恢复测试。
