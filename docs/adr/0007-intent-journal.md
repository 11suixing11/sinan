# ADR 0007：应用前写入意图日志

- 状态：已确定，MVP 不得更改。
- 对应任务说明：第 4 节第 7 条。

## 背景

切换配置链接、重载服务和记录应用版本不能共同置于一个数据库事务中。Agent 可能在任意两步之间崩溃，造成数据库与运行状态不一致。

## 决策

每次应用前先在本地状态库持久化一条意图记录，保存足以恢复的操作标识、模块、目标版本以及原状态信息。完成配置切换、服务操作和健康检查后，标记意图完成并保存已应用版本。失败则恢复之前版本并记录失败结果。

Agent 启动时必须先处理未完成意图，再接受正常对账。恢复依据已保存的意图和实际状态决定继续完成或恢复可用版本；恢复操作必须允许重复执行。

## 影响

不能把“链接已切换”视为已应用成功，也不能在恢复前覆盖旧意图。恢复需要足够的本地配置与版本文件，不依赖面板在线。未完成意图及恢复失败需要可诊断的错误信息。

## 验证

模拟写入意图后、切换后、服务操作后和记录完成前退出；重新打开状态库并恢复，验证最终状态一致且无未处理意图，失败时保留可用配置。
