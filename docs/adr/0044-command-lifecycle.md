# ADR 0044：远程命令的持久状态和确认取消

状态：源码实现及本地定向验证；生产发布、部署和多平台实机验收未执行。

## 背景

旧远程命令只有领取列表及最终结果。面板无法区分排队、实际开始和执行中，领取期限届满也不能证明已领取命令停止；中断连接或重复领取时必须保留不重执行的约束。本次增加状态和取消，不增加批量执行或实时输出。

## 决策

面板为命令持久保存 `queued`、`claimed`、`running`、`cancel_requested`、`cancelled`、`succeeded`、`failed`、`expired` 和 `interrupted`，分别记录请求、领取、实际开始、取消请求与结束时间。`cancel_requested` 不是终态，不代表设备已经停止。领取期限只自动结束尚未领取的命令，不能把执行中的命令按领取期限显示为过期。

新能力分开声明：`command:lifecycle:v1` 支持领取握手与开始报告；`command:cancel:v1` 支持确认运行取消。二者仍受本机 `allow_remote_commands` 控制，默认关闭，面板不能替代本机授权。创建命令时记录当时的能力，旧设备继续使用原命令和结果消息。

新 Agent 先把不可变命令与随机领取标识写入 SQLite，再向面板领取。领取与管理员取消都锁定同一数据库记录：排队取消先完成时，任何迟到的领取都得到已取消状态；领取先完成时，取消只能进入等待确认。旧领取接口也在返回命令前持久标记已领取。迁移前无结果的旧记录按“可能已领取”保守处理，不能承诺取消后不执行。

面板新建和领取先取得服务器行锁，再以独立查询读取退役状态，避免锁等待期间登记退役后仍使用先前快照发出命令。已登记退役的服务器拒绝新建与领取，两种待领接口均返回空；控制查询及开始、结果回执继续接收，以完成已有工作的审计与确认。回归覆盖锁等待中提交退役的并发场景。

执行仍必须经过 `Privileged`。新增有界执行观察接口，在独立受管进程创建后先持久登记进程标识，再释放标准输入启动闸。登记失败或释放前取消时，命令正文不会执行。启动闸确认后单独持久记录开始事件，开始与完成各自重传和确认；完成结果先到时，晚到的开始只补全历史，不回退终态。相同标识不同内容、重复领取的不同标识及改写终态结果均被拒绝。

运行期间取消控制请求与进程等待并发执行。断连不会取消本地超时，也不会丢弃已持久收到的取消请求。收到取消后先写本地状态，再终止受管进程，等待清理及输出管道关闭后才报告 `cancelled`。清理不能确认时保留等待确认并重试，不用发送终止信号的成功返回代替清理证明。保留每条命令 1–600 秒超时、标准输出与错误输出各 256 KiB 上限，以及超时和截断标志。

命令输出作为文本显示和持久化。无效 UTF-8 和 NUL 均转换为可显示的替代字符 `U+FFFD`，随后再按 UTF-8 字节上限安全截断，避免转换膨胀后超出限额或 NUL 导致结果无法持久确认。截断标志保留此转换后的超限情况。

执行系统出错且已有进程登记时，一律先持久设置恢复清理屏障，包含超时和正常父进程退出后的清理失败；没有确认清理就不领取执行下一个本地任务。普通非零退出且清理成功仍可正常报告失败。结束时间至少为本地持久开始时间，避免设备时钟调整、偏差取整或跨秒后产生永久无法确认的开始晚于结束记录。

Agent 重启后不会重新执行已有登记。对存有进程标识的命令先恢复清理，确认后报告 `interrupted`；重启前已经持久收到的取消可在确认清理后报告 `cancelled`。只完成本地领取登记、尚未创建进程的命令也不会重跑：与面板对齐领取/取消状态后记录中断。开始和结果的本地待确认记录在面板断连或确认丢失时继续保留。

## 平台边界

Unix 使用独立进程组。清理向整个受管组发送终止信号，检查没有可运行组成员，回收直接子进程并等待输出关闭；僵尸进程不能再执行，不作为存活负载。Linux 身份由启动标识及进程启动时钟组合，恢复时检查主机重启及 PID 复用，避免误杀新进程。其他 Unix 使用系统进程启动时间和进程组查询，仍需相应实机验收。

这项能力不是任意后台任务隔离：自行建立新会话或脱离进程组的程序不在确认范围内。界面在运行取消旁明确显示这一限制；不宣称取消可停止任意自行脱离的后代。若以后需要该保证，应另行设计 cgroup 或平台作业对象隔离，而不是扩大当前进程组保证。

Windows 提供生命周期、开始报告和未领取时的排队取消，但不声明运行中确认取消。现有进程树终止工具可用于超时与恢复清理尝试，不能据此宣称任意后代已清理；重启结果明确记为中断并说明未确认范围。旧 Agent 的开始时间显示为未上报，其可能已领取的命令不提供虚假的取消成功。

## 验证边界

本地自动化覆盖 Unix 受管进程组取消、拒绝启动闸、超时与后台清理、输出截断、开始和取消的 SQLite 恢复、协议旧消息兼容、PostgreSQL 排队取消与领取竞争、旧接口领取及取消限制、开始/完成乱序与重复消息。专用测试数据库不连接生产数据。原始结果及状态均按认证设备隔离，管理员取消按服务器和命令共同限定。

这些检查不替代 Linux 服务重启、OpenRC、macOS、FreeBSD、Windows 的真实常驻环境验收，也不证明自行脱离受管组的后台程序被终止。GitHub Actions 继续暂停，未执行远端 CI；未发布或部署。
