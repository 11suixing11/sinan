# ADR 0042：节点配置与面板部署管理

日期：2026-10-01。状态：已实现，验证范围见 PROGRESS。

用户要求对照 X-UI、S-UI 完善节点字段和部署，并确认同时包含面板安装；另授权子代理增加后台统计仪表盘。

## 参考与选择

- 以 [3X-UI](https://github.com/MHSanaei/3x-ui) 作为 X-UI 系列参考，借鉴入站设置分组、启停和运维入口；以 [S-UI 配置对象](https://github.com/alireza0/s-ui/wiki/Configuration-Objects) 的监听地址、客户端地址和协议选项分离作为 sing-box 参考。
- 原生字段以项目固定的 [sing-box v1.14.2](https://github.com/SagerNet/sing-box/tree/v1.14.2/option) 为准。独立实现有类型、有边界的参数，不引入 Xray、任意原生 JSON、额外代理协议或新的运行时实例。
- 增加节点启停、监听 IP、客户端公开端口、TCP Fast Open、TLS ALPN；Reality 增加握手目标与端口、客户端指纹；Hysteria2 增加带宽与混淆；TUIC 增加拥塞、认证超时、心跳与 0-RTT；AnyTLS 增加客户端闲置会话设置。现有 SS2022、Naive、Snell 的密钥、证书和协议版本约束保持。
- 新设置在 `nodes.settings` 保存，编译快照使用缺省兼容的同名结构。旧 API 省略设置时保留旧值，旧快照采用原缺省行为；公开端口只影响客户端和内部链路的连接端点，不改变本机监听端口。混淆秘密仅写入、服务端配置与授权客户端，管理接口不回显。
- 节点停用保留授权和账本，立即退出当前订阅资格，并通过完整配置发布停止监听；链路任一端停用同时取消该链路的有效资格，不能让入口退化成直连。离线机器仍需等 Agent 应用配置，界面不得把“已保存”当作“已部署”。
- 节点页增加部署检查和发布状态，沿用签名运行时、完整配置校验、健康检查和回滚；无需额外常驻安装器或远程命令。NodeQuality 及其他诊断能力的发布门禁不变。
- Agent 适配器的 QUIC 健康探测遵循节点 ALPN。HY2 Salamander 使用短时本机 UDP 转换和现有 QUIC/TLS 验证，取消或超时即销毁；复用工作区已有的 `blake2` 与 `rand`，不增加新的第三方依赖。不能只检查 UDP 端口占用后宣称证书健康。Naive 只给服务端设置 h2，客户端由原生实现协商，不写入其不接受的 ALPN 字段。

## 面板部署

继续采用既有 Docker Compose + PostgreSQL，提供本地 Python 标准库管理入口，复用受版本控制的 Compose、环境初始化与正式发布根。初次安装生成独立随机凭据；重复安装及升级保留环境文件、数据卷和身份。升级先保存私有备份，失败保留备份和明确错误；数据库迁移不承诺自动降级。

提供初始化/安装、启动停止、升级、备份、状态、日志和自检，支持非交互参数。管理工具不自动执行 Docker 在线安装脚本、不自动改防火墙、不触发 CI 或实际生产部署。本轮以隔离夹具与本地环境验证流程，真实容器安装和升级另行记录能否执行及结果。

## 统计口径

仪表盘仅管理员可见。服务器网卡观测和代理业务账本分别显示，按 UTC 日聚合，缺失保持未知，账单流量矫正不混入原始网卡曲线；不改变公开服务器展示的字段白名单。

## 订阅生成与获取

用户随后要求一并完善订阅，并明确选择完整 sing-box 配置与获取体验。本次复用同一份已应用快照、当前授权交集与套餐资格，提供管理员订阅状态、显式预览、复制和下载。后台默认 sing-box，旧 token URL 默认 Reality links 保持兼容；混合协议的 links 明确提示切换，不生成不完整内容。无第三方转换服务，不扩展 Clash/Mihomo。

管理员响应含当前订阅地址，跨会话重置后重新获取可以更新；获取失败移除旧内容。公开下载支持固定文件名，响应不缓存，不将凭据写入本地存储、日志或第三方链接。停用、到期与凭据重置的运行时和账本语义保持不变。
