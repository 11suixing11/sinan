# ADR 0009：统一信封与前向兼容

- 状态：已确定，MVP 不得更改。
- 对应任务说明：第 4 节第 9 条。

## 背景

面板与 Agent 不一定同时升级。如果新增字段或消息让旧版本直接断开连接，将阻碍渐进升级和长时间运行。

## 决策

消息使用统一信封 `{ v, type, id, ts, payload }`。现有字段的名称、类型和语义保持不变，演进时只添加字段。读取已知消息时忽略不认识的字段；遇到未知消息类型记录日志后忽略，不因此退出连接处理循环。

信封版本与 Agent 声明的协议版本用于表达协议能力。未知字段不等于放弃校验：已知必需字段缺失、类型错误和无效的认证数据仍应返回或记录明确错误。

## 影响

反序列化实现不能在兼容路径使用拒绝未知字段的设置。未知消息需要可保留或可识别的解析路径，不能让闭合枚举将其作为致命反序列化错误。兼容规则不授权改变已有安全语义。

## 验证

所有消息类型有 serde 往返测试；在信封及 payload 增加未知字段后仍能读取；未知消息类型被忽略且后续已知消息仍能处理；缺少已知必需字段时仍失败。
