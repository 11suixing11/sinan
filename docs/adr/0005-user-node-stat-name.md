# ADR 0005：统计用户名按用户与节点唯一

- 状态：已确定，MVP 不得更改。
- 对应任务说明：第 4 节第 5 条。

## 背景

运行时的用户计数名称为 `user>>>{name}>>>traffic>>>uplink` 和 `user>>>{name}>>>traffic>>>downlink`，不包含入站标签。同一用户使用多个节点时，仅使用用户标识无法区分节点流量。

## 决策

每条用户与节点授权生成统计用户名 `u{user_id}_n{node_id}`。该名称同时用于授权记录的 `stat_name`、运行时用户的 `name`、统计启用名单以及流量记录归属。授权的 `(user_id, node_id)` 必须唯一。

## 影响

同一用户在不同节点有独立计数，面板可以按用户或节点汇总。统计用户名不同于连接凭证 UUID，不替代认证机制。编译器不输出没有授权用户的节点入站。

## 验证

测试一个用户授权两个节点时产生不同统计用户名；两个用户在同一节点时名称也不同；编译配置与统计名单一致，流量能回归对应用户与节点。
