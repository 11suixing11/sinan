# ADR 0008：串行应用并合并为最新版本

- 状态：已确定，MVP 不得更改。
- 对应任务说明：第 4 节第 8 条。

## 背景

连续编辑模型会产生多个版本，逐一应用过时版本会增加不必要的重载与连接中断。并发应用同一模块又可能破坏配置链接与流量周期的一致性。

## 决策

同一模块只允许一个应用操作进行。已有版本正在应用时，新通知更新待处理的最新目标；当前操作完成并记录结果后，直接对账最新版本，跳过中间版本。不得取消正在执行的关键步骤来抢先应用新版本。

面板的 5 秒变更合并用于减少编译与发布次数；Agent 的版本合并用于减少已发布版本的实际应用次数，两者分别负责各自边界。

## 影响

每个版本不保证都被实际应用，但最终期望状态应收敛。通知只触发获取最新清单，不能倒退到旧通知携带的版本。中间操作失败仍必须完成回滚或恢复，再处理最新目标。

## 验证

阻塞假适配器应用版本 A，依次通知 B、C，释放后验证只应用 A 和 C；检查操作不重叠、最终版本为 C，失败路径不跳过必要的恢复。
