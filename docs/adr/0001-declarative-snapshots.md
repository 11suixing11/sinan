# ADR 0001：声明式全量快照

- 状态：已确定，MVP 不得更改。
- 对应任务说明：第 4 节第 1 条。

## 背景

面板与服务器间的连接可能中断，命令或通知也可能重复、延迟或丢失。仅依赖一次性命令无法证明服务器最终收敛到管理员期望的状态。

## 决策

面板针对每台服务器编译完整配置快照，以单调递增的 `rev` 标识期望状态。Agent 拉取主机清单与配置包，校验完整性，应用后回报结果。心跳携带各模块的已应用版本；面板发现版本不一致时重新通知。Agent 另每 60 秒轮询，以弥补通知丢失。

配置包内容由哈希标识，内容未变时不产生新的配置版本。Agent 在本地保留最后一份可用配置，面板离线不会停止已运行节点。

## 影响

通知只是加速对账的提示，不能视为成功应用的证明。面板需要分别显示目标版本、已应用版本和健康状态。配置输出必须确定，应用过程必须可重试。

## 验证

测试相同模型生成相同配置字节；重复通知不会重复改变配置；断线重连后根据版本差异补齐状态；应用失败保留或恢复之前的可用版本。
