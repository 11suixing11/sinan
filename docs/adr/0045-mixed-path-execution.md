# ADR 0045：混合链路的执行与验证

日期：2026-10-01。状态：源码实施中，最终整合与实机验收待完成。

用户现已授权实现 ADR 0040 的机场订阅与混合链路。保持受管公开入口、有序线性跳、单个运行时、入口单次计量、不可变来源及端点版本、逐阶段发布和持久恢复屏障；外部节点无需 Agent。新实现不自动取得生产订阅或部署到生产。

## 成熟项目参考

- [Sub-Store 官方文档](https://sub-store-org.github.io/doc/guide/getting-started)：参考来源管理、不同订阅格式归一化与节点预览。解析在本项目内执行，不向第三方转换服务发送订阅秘密，不执行订阅脚本。
- [Mihomo 的 dialer-proxy](https://wiki.metacubex.one/config/proxies/dialer-proxy/)：参考逐段指定下层代理的表达；本项目运行时仍固定为 sing-box，不引入第二内核或自动出口池。
- [sing-box 1.14.2 拨号定义](https://github.com/SagerNet/sing-box/blob/v1.14.2/docs/configuration/shared/dial.md)：使用确定性 tag 与 detour 编译顺序，显式解决端点 DNS。承载兼容由本项目逐跳反向计算，不能依赖原生 check。
- [固定版本的路径测速处理](https://github.com/SagerNet/sing-box/blob/v1.14.2/experimental/clashapi/proxies.go) 与 [实际 URLTest](https://github.com/SagerNet/sing-box/blob/v1.14.2/common/urltest/urltest.go)：原生按指定出站执行一次 HTTPS HEAD，不跟随重定向，完成后关闭连接。参考行为独立实现集成，不复制第三方项目源码。

## 路径验证选择

ADR 0020/0040 规划了有期限的临时代理入站。固定运行时未提供该入站认证的原生过期机制；仅设置 Agent 请求超时不能在 Agent 崩溃后证明该入口已关闭。因此本轮改用原生本机管理 API 的指定出站测试，不创建探测代理监听、探测代理账户或第二运行时。

管理 API 仅在需要混合路径的入口服务器启用，固定绑定 `127.0.0.1:18086`，使用随机高熵服务秘密，保存在受保护的签名配置中，管理界面和订阅不返回该秘密。18086 在该服务器的混合路径创建前检查冲突；旧直连服务器不新增监听。API 不对外反代，面板不提供透传 URL、任意原生管理请求或出站选择操作。

Agent 适配器只对已应用配置包中列出的确定出站、指定 HTTPS 目标和代数执行测试。目标由管理员拥有的面板 HTTPS 地址确定，不默认向第三方公共网站发送流量。请求有 UUID、期限、次数和时间预算；过期或不同版本请求拒绝。结果绑定实际 revision、配置摘要及有序版本代数，不能把一般服务健康、历史 delay 或仅端口打开当作本次成功。

原生管理 API 的服务秘密是运行时本机控制身份，不是短期数据代理账户；本方案没有可闲置或超时后被复用的临时数据代理入口。原生接口本身还有其他管理方法，因此秘密只供本机 Agent 读取，不能下发给浏览器。此选择替代旧设计的临时入站机制，保留独立认证、目标限定、有界执行与精确结果绑定的要求；它不增加 Clash 格式用户订阅。

## 应用与恢复

源刷新只新增不可变版本，链路候选一次冻结完整跳列表。先让受管依赖接收新旧内部身份，精确确认配置后准备入口候选出站；候选验证成功才切换用户路由，再验证实际切换后的出站。入口确认持久最低可恢复代数后，才撤销旧内部身份。没有新 Agent 能力时明确等待升级，不退化成直接连接。

core 只认识签名配置包中的通用作用域与代数约束，不认识机场、代理用户或链路模型。对账、重启恢复和回滚都检查持久恢复下界；已退休作用域使用明确墓碑，不能通过省略约束文件绕过。插件保存不可变部署依赖与证明，公开展示投影单独更新，不覆盖历史 source 来制造已应用事实。

## 验证边界

需要分别验证四种来源格式、恶意与超限内容、下载地址绑定、订阅身份、并发更新、确定性编译、反向承载、旧两跳数据及字节兼容、候选失败与恢复屏障、真实三/四段 TCP/UDP 和入口单次计量。HTTPS HEAD 证明该次 TCP 路径可达，不等于 UDP 或长期可用；UDP 能力与隔离运行时测试另行记录。正式签名、生产迁移、部署和远端 CI 仍按独立授权执行，未运行项目不能算通过。

## 通用验证协议与适配器依赖

通用请求固定绑定模块、作用域、代数、已应用 revision、配置摘要、UUID 和截止时间。面板仅提供设备本身的待办；终态重放必须完全一致。请求期限不可修改，已过期的屏障尝试可用新 UUID 重试同 revision；开始提交屏障后不得因超时自动回退。Agent 先持久化请求身份，验证结果先落盘再上传；中断请求不重复探测，已提交的恢复下界在新尝试中幂等确认。

适配器增加工作区已有的 `reqwest` 依赖，用于固定本机 HTTP 管理端点的禁止代理、禁止重定向、超时和有限响应读取。没有引入新的工作区第三方库。手写原始 TCP/HTTP 虽可避免此 crate 依赖，但需要重新实现 HTTP 长度、分块和错误处理，无法复用现有受限客户端习惯。该客户端的地址只能由适配器固定产生；管理员参数不能指定本机 API URL、请求头、出站 tag 或探测目标，目标仅从已经过配置包摘要验证并已应用的允许列表读取。
