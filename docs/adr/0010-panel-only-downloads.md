# ADR 0010：Agent 只从面板下载

- 状态：Agent 二进制部分已被用户 2026-10-01 的要求和 [ADR 0037](0037-server-operations-and-public-dashboard.md) 替代。以下保留历史决策；运行时与配置的面板同源约束继续适用。
- 对应任务说明：第 4 节第 10 条。
- 用户后续明确要求的 NodeQuality 节点测试例外见 [ADR 0016](0016-nodequality-diagnostics.md)；Agent 二进制后续改从 GitHub 下载，见 ADR 0037。

## 背景

受管服务器的外网访问条件不一致。由每个 Agent 独立访问上游站点获取程序会扩大依赖范围，并使制品来源、版本与完整性难以统一管理。

## 决策

Agent 的制品和配置下载仅允许来自所配置的面板，不能访问 GitHub 或其他外部下载站点。面板提供制品目录与下载接口，管理员预先将 Agent 二进制和带 `with_v2ray_api` 的运行时制品放入该目录。

下载前检查 URL 来源，拒绝清单或重定向引入的外部来源；下载后按发布的 SHA-256 校验再安装。上游源码获取与构建由管理员运行 `tools/build-singbox.sh` 完成，不放进 Agent。

## 影响

面板必须能够提供清单引用的制品；制品缺失或哈希不匹配时部署应失败并保留已有可用版本。面板访问失败不能触发外部站点回退。安装脚本升级 Agent 也从面板下载。

## 验证

测试正常面板地址可下载，外部来源和跨来源重定向被拒绝，哈希错误不会安装；检查 Agent 运行路径没有上游站点访问逻辑。
