# ADR 0049：带目标授权的轻量三网周期监控

日期：2026-10-02。关联：#63。

## 决策

复用 `latency_tasks`、`network_probes`、`ProbeSpec` 和已有拨测历史；以主线 `monitor.authorization` 为唯一持久化/协议授权，保留绑定 `identity`（方法、目标、端口、IP 家族）与 `Owned`/`Consent`，在 `monitor` 新增 `network` 标签，不并存第二份授权，不建立第二套调度器。每个目标显式记录电信、联通、移动或其他线路、目标地区、自动/IPv4/IPv6、授权依据（自有/明确许可）、来源引用、适用范围、确认状态和可选到期时间。授权范围应覆盖目标、TCP/ICMP 方法、频率和执行服务器；公开可达不能代替许可。所有表单的目标与授权记录默认留空，系统不内置第三方探测地址。

未确认、缺少完整来源/范围、到期、停用或配置租期失效的目标不进行 DNS、TCP 或 ICMP 请求。在线新版 Agent 每 30 秒同步，撤销或到期后下一次 1 秒调度检查取消正在运行的任务。断网、404、401、无效响应或配置无法落盘不延长上一份配置的 120 秒租期。缓存时间晚于本地时钟也按不可用处理。只有仍处于有效租期且内容相同的目标可以持久化本轮结果。

旧 Agent 的解码器禁止额外字段，因此旧 `/api/agent/v1/probes` 保留原八个字段，并明确返回 `enabled=false`。主线授权 Agent 的 `?authorization=1` 仍投影原有 `monitor` 三字段，避免新增 `network` 被旧解码器拒绝；本版仅调用 `/api/agent/v1/probes/authorized`。新版连接旧面板时该接口不可用，租期到期后停止；旧版在线 Agent 下次配置同步暂停。完全断网的旧版程序仍可能沿用自己的旧缓存，源码迁移无法远程改变它，需恢复连接或升级 Agent 后验证停止，不能宣称对离线旧二进制即时撤销。

迁移 0029 只暂停缺少 `monitor.authorization` 记录（不存在或 JSON null）的旧单机/统一任务，停止其默认分配并增加任务修订；已有主线授权记录保留原意，合法、到期、撤销或异常记录由统一 `runnable_at()` 判定，不在 SQL 重复整套校验；不删除任务、测量 ID 或历史。重新确认授权即可继续使用同一个测量 ID；更换方法、地址、端口、运营商、地区或 IP 选择必须新建，避免将历史改归另一线路。取消服务器分配再分配使用新的 ID。已删除目标的离线迟到结果仍确认后丢弃，重复结果仍按 ID/设备/内容摘要去重。

## 成本和结果

保留每节点最多 32 目标、最多 4 个并发、间隔 10–3600 秒、每轮四次、DNS 2 秒、单 TCP 连接 1 秒、每轮 12 秒、ICMP 有界进程/输出等预算。本机结果 outbox 保留最多 4096 条/两小时，上传每批最多 64；存储错误只放弃该次无法持久化的样本并记录原因，不终止周期监控任务。此能力不触发完整 NodeQuality、硬件基准、排行榜上传或系统/代理配置修改。

共用遥测持久化、设置更新、结果确认、已确认状态清理与连接时钟更新只将 SQLite FULL、IOERR、BUSY、LOCKED 视为可恢复写入失败；每个操作的一段故障仅记录一次，下一周期重试并记录恢复。事务失败保留旧数据/设置/时间，不能把未落盘的配置当作续租，不能提前确认本地队列。已认证连接可以沿用旧持久化时钟发送心跳，并重试最新经过认证的时钟更新；身份、协议、结构与数据库损坏错误仍保留原来的失败路径，不清库重置。

结果保留主线可选 `address_family` 并新增已完成 `attempts`；字段缺失时不序列化，保持旧结果摘要的序列化输入兼容。真实四次 TCP 连接被拒绝/超时会记录原因、100% 失败率及空延迟；DNS、工具、权限或整轮超时没有完整尝试证据时保持未知。授权过期、暂停、设备离线或样本过期的当前指标保持空缺，历史曲线继续可读。三网页按运营商/地区展示每台服务器，并支持服务器筛选；单机/看板同样显示方法、目标、时间和网络版本。公开看板清除目标及授权来源/范围，并隐藏原始错误。

## 验证范围

回归入口：protocol 的旧配置/旧结果兼容测试；agent-core 的真实 IPv4/IPv6 回环 TCP、被拒绝端口、错误 IP 版本、无授权、并发/撤销/到期/租期及存储故障隔离；panel 的授权校验、旧接口投影、身份不变与历史去重；Web `probes.test.ts` 和 `carrier-monitoring.mjs`（1440/390）。所有联网测试仅使用明确的 TEST_ONLY 自有回环目标，浏览器拒绝外部请求。

本批先准备实现与回归，按用户要求暂不执行测试或构建。已准备 `tools/carrier-monitoring-acceptance.py`，按 [专用验收配方](../acceptance/carrier-monitoring.md) 在最终冻结源码的专用 Debian 机器验证四并发、128 MiB Agent、持续回环代理、真实断连/重启/满盘/恢复/迟到与去重。当前尚无执行收据；实际旧二进制升级与 ICMP 平台权限另行记录，源码回归不代表该实机联合负载签收。
