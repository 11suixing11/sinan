# ADR 0011：本地 API 仅监听回环地址

- 状态：已确定，MVP 不得更改。
- 对应任务说明：第 4 节第 11 条。

## 背景

运行时 v2ray_api 提供统计 gRPC 服务但没有认证。将它暴露在公网或局域网接口会使非本机调用者访问内部统计能力。

## 决策

所有本地 TCP API 只监听 `127.0.0.1`。sing-box 的 v2ray_api 默认监听 `127.0.0.1:18085`，配置编译与适配器校验均保持这一约束；不能改为通配地址或外部接口地址。

Agent 的 `status` 使用仅 root 可访问的 Unix socket 查询运行中状态，不增加对外 TCP 控制端口。面板公开管理与 Agent 接入 API，以及节点代理入站不属于本地 API，按各自配置监听。

## 影响

统计客户端必须在同一台服务器连接回环地址。本地监听约束不能被认为提供了用户认证，也不授权增加防火墙或 nftables 功能；后者属于 MVP 禁止范围。

## 验证

编译器黄金文件固定本地统计监听地址；测试拒绝非回环的统计地址；真实环境检查监听套接字及 status socket 权限，并确认健康检查能够访问统计 API。
