## 最终行为与整合补修

- 看板轻量状态和静态资料独立刷新；Agent 默认 1 秒采样、3 秒实时上报和 60 秒历史批量写入。实时接收不删除持久待确认样本，历史、去重收据及精确网卡账本事务提交后才 ACK。历史保留真实零值、未知、缺桶、有效样本数、加权均值及极值。容量扩展字段只接受 uint/null，匿名旧数据也使用白名单；历史初始化不让前八台忙服务器阻挡后续健康服务器。
- 每日汇率保留明确 Frankfurter 来源、日期和真实旧成功；缺失币种不编造估值，未来时钟证据保持过期。九类 Webhook 预设与 Telegram 独立投递，按实际渠道回执判断成功；Discord 等待消息确认，矛盾错误回执拒绝成功，Retry-After 支持有界 HTTP 日期、向上取整与完成后计时。测试不发送真实通知。
- DDNS 实现位于 `plugins/ddns/panel/`，通过薄 Rust 桥登记，按服务器显式启用，默认关闭。仅使用 Agent 当前已上报的适当家族公网地址；Token 只写不回显、不传给 Agent。缺地址、过期、离线、退役或插件停用时保留远端 DNS。删除或暂停本地规则不删除解析。
- Cloudflare 两次读取后、实际写入前重新核对租约、修订、设备、插件和本次地址。规则/服务器锁只覆盖有界写入；先取得服务器锁，再以新 READ COMMITTED 语句读取退役状态，避免锁等待后的旧快照。迟到完成不能覆盖新修订。PATCH 保留已核对的身份，不改他人备注/标签；创建标记支持回执丢失后的读取恢复。同名重复、CNAME/NS、身份不符及矛盾错误不自动接管。
- DDNS 单独排除新增文档/基准/退役特殊地址，未更改共享 IP 分类。报告接收时间不等于第三方探测时间：源码 Agent 即使地址未改变也周期报告，仍保留原发现缓存；公开 Agent 0.3.0 是否具备所需行为不能由本轮源码认证。
- 保留主线授权拨测、命令退役清理、统一节点/混合链路、订阅与历史、旧 Agent/PowerShell 接入保护、签名信任、账本及 NQ r19 的完整任务门禁。新增插件导航曾把桌面底部入口推出视口，最终仅补桌面侧栏滚动，并实际点击系统管理员入口验证；移动布局不变。
