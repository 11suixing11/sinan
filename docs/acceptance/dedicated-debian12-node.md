# 专用 Debian 12 测试节点：准备与独立验收

对应第 0 步“准备专用小规格测试节点”。完整诊断的资源症状另记一项验收，不将准备就绪等同于 P0 整体验收。

## 已执行的准备

- 在取得明确授权后，将选定的 Debian 12 节点改为专用测试用途。停止并禁用原 `xboard-node.service`，保留原配置与身份；读回为 inactive、disabled、MainPID=0。
- 核实资源为 447 MiB 内存、约 12 GiB 剩余磁盘、已有 2 GiB swap。停止原业务后、安装测试服务前 MemAvailable 为 345 MiB。没有在其他现有代理节点运行完整硬件测试。
- SSH 凭据备份保存在操作者本机的私有目录，目录 0700、凭据文件 0600。测试使用独立 SSH 配置、known_hosts 与 agent socket，不修改全局 SSH 配置，不开启 agent forwarding。密钥与环境凭据未进入仓库。
- 构建和 PostgreSQL 在独立、受限容器进行；测试数据库没有生产数据。测试面板只绑定宿主回环端口，经 SSH 隧道供测试设备访问，使用独立管理员、设备、代理用户和授权。
- 从主线 `541f52d` 在 Debian 12 工具链构建 Agent/面板 0.3.0，使用公开 TEST_ONLY 信任根准备并独立验证签名安装包。运行时固定 1.14.2，NodeQuality 固定入口版本 `a92fca6c0067df29ddd03fdc2fee6f3000f64545-r2`。本次 Agent 是 GNU 调试构建，仅用于私有测试，不将其表示成正式 musl 发布产物或发布正式 Release。
- bootstrap 拒绝位于普通账户目录的信任根；将独立核对的测试公钥和验证器放入 root 所有、受保护的目录后，签名安装成功。未关闭或绕过签名验证。

## 独立验收结果

设备通过正常注册和认证连接测试面板。Agent 与 sing-box 配置健康，实际 systemd 单元均为 active/running；内核及 systemd 属性读回为 OOMScoreAdjust=-500、CPUWeight=1000，初始 NRestarts=0。原代理服务仍为 inactive/disabled。

未提交节点地址、私钥、管理员密码、注册令牌或订阅内容。原始命令输出、配置摘要和安装日志仅保存在私有证据目录；仓库记录的是脱敏资源与验收结果。

## 使用边界

默认完整诊断的 MemoryMax 为 512 MiB，高于该机物理内存；启动前预检 PR 要求再留 256 MiB，因此该节点应拒绝默认完整验机，并给出内存不足原因。它适用于低内存拒绝、短命 cgroup 限额、互斥、取消清理和恢复测试，不能以“服务装好了”宣称完整硬件验机可安全通过。

403/429/超时、磁盘不足、重启/断连、取消、重复提交、部分报告、持续代理流量等故障矩阵分别由对应整改 PR 验收。本项确认的是隔离边界与测试服务就绪。
