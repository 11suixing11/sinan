# IPQuality 最小闭包贯穿验收

阶段：整步实现及集中验收完成，八组有效合同共 230 项通过；独立 Debian 12 ARM64 上实际离线派生成功。尚未实际 prepare/build/export，也没有获准的 builder、可发布最小 rootfs 或节点运行签收。可机读结果见 [本步收据](ipquality-minimal-profile-local.json)，设计见 [ADR 0070](../adr/0070-ipquality-minimal-profile-chain.md)，原缺口见 [Issue #146](https://github.com/theLucius7/sinan/issues/146)。

## 本步范围

最小包／源闭包不能只在 derive 时检查。IPQuality prepare 重新认证派生父链、真实缓存和绑定，再重放固定 profile 的离线选择；prepare、build、export 与制品校验绑定同一份公开证明。私有路径和文件身份只保存在准备上下文，公开证明不能泄露原节点细节。共用 NodeQuality 默认路径不启用这些扩展。

旧真实派生磁盘拒绝及 117 项有效合同证据保留在 [前一步记录](ipquality-derived-inputs.md)，不重复标记为本次通过。本步实现与验收代码先全部完成，冻结后集中运行；最终 678 份功能输入 SHA256 为 `34303534adf539eac2d91a45b4d8793c7f56dd35a3d56e7ce9701b100b520053`。功能输入在最终补验后保持不变。

IPQuality 准备入口现在必须明确给出 `--lock <绑定目录/inputs-lock.json>`、`--cache <原缓存>`、`--derived-inputs <派生目录>`、`--derived-binding <绑定目录>`、`--output <全新准备目录>` 和 `--approved-builder-image-sha256 <独立审核通过的实际摘要>`。后一个参数仍按原审批边界核对，不因创建派生证明获得授权。`collect`、旧 `bind --materials` 与 NodeQuality 工厂语义保持；普通 IPQuality prepare 缺少真实派生及绑定时拒绝。build/export 读取准备目录保存的私有上下文并再次认证，不要求调用方重新声明最小性。

## 存储和真实操作边界

本次新增输出空间与原八 GiB 根盘分开，根盘和约一 GiB 原收集正文均保留。新增盘是最多 1536 MiB 的自有 raw 文件；宿主准入按最坏完整分配加 512 MiB 管理空间与 256 MiB 根盘／日志余量核算，不能把稀疏文件当免费容量。Lima 原配置备份和全部原始动作日志保存在私有目录，未知既有磁盘、已启动测试任务或身份变化时拒绝。

首次格式化只作用于本步独占创建的空盘。确认设备／UUID 后，将自动格式化关闭并正常重启，随后记录新的启动与 SSH 管理基线；后续派生只与这一基线比较。原节点历史 boot 或 SSH 身份不跨重启冒用。实际 APT 选择、正文认证和新输出写入在有界单元中执行，父材料保持只读。

首次存储控制器因已启用但无进程的 sing-box slice 拒绝，未停机、变更磁盘或修改配置。只修正空 slice 的识别：两次稳定观察必须确认所有后代无进程、无活跃子服务及无代理业务进程；未知情况仍拒绝。补验随后完成独占新盘创建、首次格式化与两次正常停机／启动，实际设备独立于根盘，关闭自动格式化后 UUID 保持，原根盘及父缓存身份保持。原拒绝、控制器输入、配置备份和完整动作日志均保留。

存储改变后仅执行一次真实离线派生，退出 0，约 14.33 秒；重新核对官方签名、旧材料和正文，再由隔离 APT 精确选出 130 个二进制包、91 个对应源版本、289 份源文件。选中逻辑材料为 429,686,196 字节；外借缓存没有新增正文分配、复制、下载或宿主安装。新输出峰值实际占用 61,374,464 字节，结束时输出盘可用 1,444,077,568 字节；派生期间根盘最低可用 676,274,176 字节。512 MiB 磁盘、1024 inode 和 256 MiB 可用内存管理保留保持。

实际派生 MemoryPeak 为 268,435,456 字节，`memory.events.max=26180` 表示发生内存回收压力，`oom/oom_kill/oom_group_kill=0`，没有把它描述为无资源压力。原父材料由内核只读保护，结束后身份与摘要保持；所属进程、挂载、cgroup 和临时目录已清理，存储变更后的 SSH／启动基线保持。此环境没有运行新 Agent 和持续 sing-box 业务，不能将管理进程保持当作联合负载验收。

新增输出盘只为本步派生解除已知空间条件，不能证明 prepare／build 的独立副本、展开目录与管理预留都能容纳。后续完整工厂仍须按实际阶段预算准入，不降低 512 MiB guest 磁盘、1024 inode 或可用内存管理保留。
