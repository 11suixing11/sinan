## 本地

清理三项编译目录和一份旧缓存归档；随后删除 86 项旧阶段/测试目录和前端依赖副本，以及 32 个旧散文件。两台 Lima 测试虚拟机先确认 Stopped，再通过实例删除命令移除，未使用强制杀进程。删除前核对路径、所有权和打开文件，删除后按清单确认不存在。

测试私有根由约 14 GiB 降到约 60 MiB，当前源码树由约 706 MiB 降到约 18 MiB。清理后本地磁盘可用约 25 GiB，已满足既有 4 GiB 管理预留。当前源码、测试用例、已跟踪的前端 dist、最新可用 Release、最新上下文摘要和凭据备份保留。其他七个 Git 工作树没有编译或依赖缓存，其源码和 Git 历史保持；没有清理全局 Cargo 缓存或其他项目。

另一共享主机已删除 12 个旧测试容器、两个专用测试卷、六个旧测试目录及一个旧验收镜像；两阶段加权限补清的文件系统可用空间观测净增 10,296,856,576 字节，约 9.59 GiB。生产面板/数据库的容器身份、运行状态及最新构建镜像前后保持，不使用全局 prune。另有一份旧镜像普通删除失败后保留，没有强制删除依赖层。
