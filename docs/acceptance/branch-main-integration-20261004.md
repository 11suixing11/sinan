# 2026-10-04 其余分支与 main 整合

用户要求把 GitHub 仓库其余分支合入 `main`，随后删除已合入分支。本轮将主线 `f32aa54` 与 `claude/sinan-scan-refactor-odrgr3` 的 `c8ce3f2` 整合；保留双方已有实现与历史记录，解决迁移编号、宿主/插件边界、权限及界面冲突。源码先集中完成，之后再执行整合输入需要的本地检查。GitHub Actions 继续按现行约束暂停。

本记录描述整合取舍及本轮集中本地验证。双方旧验收记录只证明各自记载的提交、环境和输入；下列新结果对应这里注明的整合输入。

## 数据库与架构

主线已有迁移 0001–0058 保持原内容与校验和。分支六个新增迁移按功能和原先顺序追加到主线，避免把既有数据库的版本解释成另一份 SQL：

| 分支原编号 | 主线新编号 | 内容 |
| --- | --- | --- |
| 0049 | 0059 | `usage_daily_rollup`：派生 UTC 日汇总、重建及精确窗口查询 |
| 0050 | 0060 | `server_last_contact`：保留真实设备联络时间 |
| 0051 | 0061 | `ordered_source_parity`：有序来源设置、预览、采用状态及数字别名 |
| 0052 | 0062 | `source_migration`：来源映射、显式迁移状态、视图与只读归档保护 |
| 0053 | 0063 | `legacy_takeovers`：显式旧两跳接管及回滚材料 |
| 0054 | 0064 | `mixed_conversions`：逐条转换状态及长期恢复下限 |

0059 的 `singbox_entitlements` 同时保留主线 0052 的手动额度抵扣。窗口中的原始用量由 `singbox_usage_window` 提供，然后减去同一用户、同一账期的 `singbox_quota_credits`，并用 `GREATEST(..., 0)` 计算已用额度及耗尽状态。不得以日汇总覆盖已存在的手动重置语义，也不删除或重写账本。

宿主 `crates/panel-host` 承担通用鉴权、服务器、诊断、运维、恢复和插件接口；具体业务留在独立插件 crate。组装 `sinan-panel` 登记插件并保存唯一迁移序列，保留已有 `sinan_panel::*` 公共路径。主线终端会话隔离、当前权限复核、外部变更单次意图、未知结果只读核对和恢复材料验证随对应模块保留，不能因移动文件回退。

来源迁移、旧两跳接管和 mixed 转换均需要管理员显式执行；合入代码不会自动迁移生产来源或切换链路。原凭据、授权、历史用量、恢复屏障、单运行时与 NodeQuality 完整执行门禁仍成立。
