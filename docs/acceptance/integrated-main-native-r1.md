## 资源清理的实现边界

健康探测的UDP抽象只有一个实际FD，单报文且不启用GSO/GRO/ECN；两秒握手预算预留100ms供关闭与专属Quinn任务abort/join。Salamander转发由同一probe future驱动，没有独立后台任务。正常、错误、内层超时执行显式关闭与等待；外部取消的Drop同步关FD并abort，但不能await，不能描述为已确认全部join。清理超时报告失败。

TCP Journal同步create_new后保留UID/dev/inode，异步写入/sync完成后以没有await的rename提交；失败清理本次owned pending，旧章节/结果与既有或被替换的外来对象保持。Drop覆盖外部future取消；少量同步FS调用本身不能抢占卡死的内核文件系统，此边界不等于任务单元已完成清理。
