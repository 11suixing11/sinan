## 覆盖的行为

- 管理白名单、分类型身份、200 项批量修订比较与整批回滚、引用保护、别名/标签/排序持久化；外部停用不改变冻结链路或历史账本。
- 受管节点复制先核对修订，四种协议重新生成身份或秘密，不复制用户授权；旧页面复制拒绝后不创建节点。
- 预览不创建正式来源，确认仅采用勾选项且不再抓取；过期、重复、无效选择、解析器变化、未登录拒绝；大小、数量、期限与解析并发有界。
- 来源同步保留采用状态、别名和墓碑，新节点待采用；采用检查来源设置/身份/节点版本。自动开关保留周期，304 与失败保留可信缓存，未知流量不作零。
- 外部固定/跟随授权检查身份、版本、目录状态与套餐；更换来源/归档/缺失/歧义/停用排除后续订阅，普通抓取失败可保留可信旧版。
- 完整客户端组合已生效受管节点与有效外部授权；名称/顺序进入外部订阅，稳定 ID 防碰撞，旧无外部授权的编译字节保持。链接格式不静默漏掉外部节点。
- 手机公开端口、筛选后的排序、只改备注不固定来源名称、内联编辑不覆盖周期；轮询/读取失败时禁写，冲突保留草稿。
