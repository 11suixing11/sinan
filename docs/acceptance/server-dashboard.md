# 独立服务器看板验收

日期：2026-10-01。验证基线为 `de299906f56158ff5bc5271403f9cca091f1ae7a` 加本 PR 的前端与文档变更。没有操作生产面板或修改服务器配置。

## 交付范围

在既有 `web/src/display` 页面上补齐独立看板，而非增加第二套监测后端。新增规范地址 `/#/dashboard`、`/#/dashboard/<服务器 ID>`，旧 overview 书签兼容。后台侧栏“服务器看板”及服务器页“打开服务器看板”提供跳转，看板/详情可返回管理后台。认证仍在加载业务页面之前完成。

卡片与表格共用两个现有只读汇总接口，提供搜索、状态/地区/分组组合筛选、排序、深浅主题与全屏。表格只展示首个启用的拨测目标，其余到详情查看；不把不同目标的延迟混成一个分数。隐藏服务器不进入任何模式、筛选选项或汇总。

读取器支持真实成功时间、暂停、手动单次读取、隐藏标签取消与恢复、单次 12 秒超时和不重叠请求。暂停或服务器快照超过 15 秒未更新时不将历史在线状态/速率称为实时。指标缺失、离线、读取失败、设备全隐藏和真正空列表分别处理。

Bun 固定 1.4.2，构建容器限 2 CPU / 1 GiB，以工作区用户执行，避免生成 root 所有的前端文件。浏览器使用已有 Playwright 1.59.1 / Chromium，禁外网容器限 2 CPU / 1500 MiB，仅访问自身回环静态服务并拦截 API，数据全部为明确的虚构夹具。所有截图来自真实构建产物，桌面深色表格与手机浅色卡片已目视核对。

新浏览器用例除了导航和界面，还使用测试时钟验证暂停时两个接口均停止、单次刷新不会恢复定时任务、隐藏标签不继续请求、恢复显示立即读取，以及慢响应不叠加轮询且超时取消。未完成首次读取即暂停时不会误报“没有服务器”。全屏通过显式按钮操作，登录失效后仍回到登录页并停止业务读取。

调试时发现禁外网环境的 `navigator.onLine` 为 false，但回环服务仍可用，因此产品逻辑不能依赖该标志禁用读取。现以实际 API 响应与超时判断可达性，保留认证；没有通过放开容器外网绕过问题。早期夹具使用 null 代替协议要求省略的 CPU 字段导致后台格式化失败，已修正夹具使用省略字段，未更改无关后台业务。

## 未执行范围

本轮没有变更 Rust、数据库迁移、Agent、代理配置或诊断执行，未重跑 Rust/PostgreSQL 完整工作区，也未运行设备实机、证书、跨平台原生服务等验收。不复用此前 PR 的 Rust 通过数量为本次背书。

浏览器结果仅涵盖 Chromium；Safari/Firefox、实际显示器全屏限制、大规模服务器负载及线上数据接入未在本轮验证。既有隐藏设置是展示筛选，不是新增权限体系；所有管理接口仍需要管理员认证，不增加匿名看板。

源码和前端构建产物一并交付 PR，但没有合并、部署、签名或发布。既有 CI/平台/发布四个工作流保持暂停，未触发、重跑或恢复它们；本地成功不等于远端 CI 或生产已经更新。
