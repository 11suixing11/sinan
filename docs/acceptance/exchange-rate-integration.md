# 每日汇率来源与整合边界

源码固定请求 `https://api.frankfurter.dev/v2/rates?base=CNY`，失败可回退 `https://api.frankfurter.dev/v1/latest?base=CNY`；无用户提供的上游地址、代理、重定向或认证密钥。每次请求最多 8 秒，刷新外层最多 20 秒，响应体限 256 KiB。并发领取采用数据库租约；普通读取不发出下载请求。

依据 [Frankfurter v2 官方文档](https://frankfurter.dev/) 与 [v1 文档](https://frankfurter.dev/v1/)，v2 默认混合官方来源的参考汇率，不冒称单一 ECB 直报或实时成交价；v1 使用 `frankfurter-ecb` 来源标识。仅接受 CNY 基准、有限正数、合法币种标签和真实日期；不同币种原始数据日可不同，逐币保留，不补填另一天或硬编码缺失币种。CNY 同币种单位值 1 不代表一次上游抓取成功。

成功快照完整替换，下一次刷新为 24 小时后；失败保留原成功值、日期和抓取时间，显示过期并一小时后重试。墙钟回退使原抓取时间或最早数据日期位于未来时，原数据仍可读但不显示新鲜。无成功缓存时显示不可用；展示缺少币种时不得填零或估算换算值。参考折算不证明实际付款、可成交价格或资产变现价值。

整合回归源码覆盖缓存不可用、失败保留、并发与过期租约、旧请求不得覆盖新结果、管理员手动刷新冷却、日期/基准/重复币种/数值拒绝、墙钟回退，以及回环响应体上限和重定向拒绝。作者已有专项记录不认证本次整合补修；遵用户要求，源码全部冻结后统一执行首次验证，中途未运行测试或构建。

本次只读取公开官方文档，没有请求真实汇率数据，也没有修改生产配置、执行部署或恢复 CI。公开看板汇率读取沿用公开开关和 `no-store`；匿名服务器白名单仍不得公开成本。
