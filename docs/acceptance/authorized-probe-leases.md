## 独立范围

- 协议：旧八字段数组及缺 execution 的旧结果字节保持；新许可身份/期限/授权、重复目标、上限、未知字段及目标上下文拒绝。
- Agent：旧一天缓存不能执行，冷/重启动必须新许可；单调期限和请求耗时；断连/换连接/空集合/依据改变在途取消，旧 GET 迟到不能恢复；GET 401/403/错误设备/非 JSON/挂起；SQLite 高水位与持久周期、四路公平性和未知存储状态；私有父子孙执行脚本取消后没有继续写入，退役 gate 可取得。
- 面板/PostgreSQL：缺依据与自然到期不发任务，修订/分配/取消一致；真正签发收据、复用不延寿、有界保留、执行上下文与迟到幂等确认；原 0025 数据迁移保留；匿名不泄漏来源/依据或 execution。
- 前端：单机、统一任务、新服务器三入口的明确依据/地区/截止，授权过期和未知，读失败/pending/过时版本或服务器选择复核，草稿保留及零错误写入；实际 dist 桌面/390px、原监控与接入能力保持。
