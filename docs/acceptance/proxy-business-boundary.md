# 核心与代理业务边界：独立验收

对应 Issue #26 的“先写 ADR、仓库规则和 CI 禁用词”条目。本项不搬迁业务代码或数据库。

## 自动验收

运行 `python3 tools/check-core-boundary.py` 和 `python3 -m unittest discover -s tests -p 'test_core_boundary.py'`。

- 当前 core 所有文件通过；向新的 Rust、SQL、路由或注释加入 user/subscription/quota 引用即失败，支持复数、蛇形及驼峰标识符。
- 原有运行时名称禁令继续有效，包含原生系统文件也不例外。
- 原生账户 API 和 SQLite 版本 API 的表达式例外仅适用于指定文件；同一行追加 `user_id` 仍失败，复制到其他文件也失败。
- 改名仅涉及原生本地变量和示例 URL 凭据，无系统 API、模型、路由、持久化或协议变动。执行 workspace 格式检查，CI 继续执行 Clippy 和完整回归。

## 故障矩阵边界

小内存、磁盘不足、403/429/超时、Agent 重启、面板断连、取消、重复提交、部分报告和持续代理流量不由静态门禁处理，运行行为保持原有实现。本项逐个记录为“不适用：仅架构文档和 CI 门禁”；相应运行场景分别在 P0 及业务搬迁 PR 中独立验收。

## 后续搬迁必须验收

未启用插件的服务器不显示代理业务；迁移前导入的订阅仍由旧路径取回相同用户 ID 和令牌；节点凭据、授权、历史流量保持；服务器网卡计量保留在 core，代理计量的 epoch 与套餐周期分开。以上结果尚未由本 PR 验证。
