## 实现与兼容

统一受管直连、数值链路和独立外部节点目录，保留 UUID 有序链路的路径、运维、引用、部署与回收界面。标签、备注、排序属于管理元数据；实体启停沿用原资源修订与发布语义。删除共用原退役和有界引用检查；缺失选中不可变版本的损坏历史继续保护已保存身份。来源采用强制核对 metadata revision、来源代次和精确版本，旧草稿不能重新激活删除墓碑。用户外部绑定冻结原用户、授权修订和版本，已有失效绑定可保留或明确移除；订阅每次重新检查授权。

来源预览、确认保存与后台刷新共用四个解析许可。阻塞解析任务持有许可；取消等待者不会提前释放仍在运行的任务，成功后请求继续持有至持久化完成。预览在拓扑锁外解析，保存时重查原私有内容、解析器、身份和期限，不二次抓取。保留 2 MiB、5000 节点、64 层、SSRF、脱敏和 parser2 边界。前端写入同步检查当前资源、角色、版本和目标，失效时保留草稿；克隆暂失原服务器不自动改选。

原 0001–0045 SQL 保持原字节；作者三份迁移原字节调整为 0046–0048，ADR 0076 追加于既有 0061–0075 后。数值与 UUID 身份、不可变历史、原订阅、凭据、计量账本和单运行时保持。高级 WebSocket、HTTPUpgrade、gRPC 配置及旧入口兼容同时保留。
