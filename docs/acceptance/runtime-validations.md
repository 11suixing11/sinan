# 通用运行时验证与恢复下界验收

本记录属于 ADR 0045 的通用协议、Agent 恢复安全与 sing-box 适配器部分。混合路径编排、源解析和真实路径承载另行验收。

## 源码行为

- 能力 `runtime:dependency-validation:v1` 与通用 `probe` / `barrier` 请求；队列和结果绑定设备、模块、作用域、代数、配置 revision、摘要、UUID 与不可修改的截止时间。
- 只有相同已应用 revision/摘要且制品再次验签通过才能执行；未完成部署 intent 阻止验证。适配器只从已应用允许列表读取 scope/代数对应的指定出站和 HTTPS 目标。
- 本机管理客户端固定回环地址，禁止环境代理及重定向，认证秘密不进入请求结果；十二秒 HTTP 超时及十六 KiB 响应上限。请求截止时间另行限制执行。
- 屏障在模块锁内校验 active 代数后将最低恢复代数写入 SQLite；确认在持久化之后。所有后续配置验证、重启、切换和回滚均检查下界；省略约束或低代数不可恢复。退役作用域必须显式保留足够代数的墓碑，active 与 retired 不能同时声明同一作用域。
- 请求结果先持久化再上传；中断请求不重复探测。过期屏障可用新 UUID 对同 revision 创建新尝试，旧请求身份与期限不修改。提交屏障后超时仍不能回退，已持久下界在重试时幂等。
- 路径配置中的构建特性要求在适配器 prepare 阶段与真实 `version` 输出的 Tags 精确匹配，缺少必要特性不能应用候选配置。

## 验证清单

本地已通过：协议测试 5 项；适配器单元测试 11 项（另有 1 项既有真实运行时测试保持忽略）；对账集成测试 12 项；通用队列 PostgreSQL 测试 2 项；Agent 的 `runtime_` 定向测试 12 项，其中包括提交屏障后回执丢失、请求过期、SQLite 重新打开后原样重放成功结果。专用 PostgreSQL 运行在回环测试端口，使用独立测试库。

这些测试覆盖固定目标及强身份校验、错误密钥/URL/未知字段拒绝、有界本机 HTTP 与重定向拒绝、精确版本与终态不可改写、屏障过期重试、SQLite 重新打开后拒绝代数回退、缺失约束、显式墓碑以及回滚 intent 保留。core 分层检查与差异空白检查通过。全工作区格式、clippy 和测试仍由最终整合验证统一记录。

本子任务使用受控本机 HTTP 夹具；整合中另以真实 sing-box 1.14.2 验证本机管理 API、三/四段 TCP/UDP 及中间段停止后的失败行为，证据见[隔离网络夹具](mixed-path-local-fixtures.md)。这些分开执行的证据不能替代完整 Agent 分布式发布和恢复、不同原生构建、入口实际计量、生产网络及各系统服务验收。路径 HEAD 成功只证明该次 TCP 检查，不代表 UDP 或长期可用。CI 仍暂停，未运行的 CI 不算通过。
