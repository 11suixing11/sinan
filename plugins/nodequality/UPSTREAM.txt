The artifact contains the unmodified upstream script and full upstream license.
The runner and its bounded report collector are maintained by Sinan.
The chroot command shim maps the pinned loader's fixed AMD64 trace download to
the corresponding upstream ARM64 asset on ARM64 hosts; source bytes stay intact.
NodeQuality downloads BenchOS v0.0.2 and additional upstream test loaders at run
time. Only an explicit administrator diagnostic action runs those tests.
Linux runtime prerequisites: Bash >= 4, Python 3, curl, tar, base64, mount,
umount, chroot, coreutils, and systemd with private mount namespaces.
